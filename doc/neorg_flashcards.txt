SETUP                                               *neorg-flashcards-setup*

Install the plugin with your plugin manager, then configure at least one
language:
>
  local presets = require("neorg_flashcards.presets")

  require("neorg_flashcards").setup({
    flashcards_dir = vim.fn.expand("~/notes/flashcards"),
    default_file = vim.fn.expand("~/notes/flashcards/cards.norg"),
    default_kind = "japanese",
    languages = presets.only("japanese"),
  })
<

Use `presets.only("chinese")` for Chinese, or pass a custom `languages` table.

Neorg is optional. Card storage and collection scans always use `.norg` files,
but the plugin reads those files directly. Without Neorg they are ordinary
plain-text buffers. Files ending in `.md` or `.txt` are not collected.

==============================================================================
COMMANDS                                         *neorg-flashcards-commands*

                                                        *:NeorgFlashcardOpen*
:NeorgFlashcardOpen
        Create or open the configured default flashcard file. Missing parent
        directories are created.

                                                         *:NeorgFlashcardAdd*
:NeorgFlashcardAdd [kind]
        Open the add-card form: an editable scratch buffer with one line per
        field. Edit the values, save with <C-s> (insert/normal) or <Enter>
        (normal); the form stays open for the next card, `q` cancels. The card
        is added to the current `.norg` file, or to `default_file` from any
        other buffer. Uses `default_kind` when [kind] is omitted.

                                                      *:NeorgFlashcardReview*
:NeorgFlashcardReview
        Review all valid cards under `flashcards_dir`. This is the cram mode;
        for daily study prefer |:NeorgFlashcardReviewDue|.

                                                   *:NeorgFlashcardReviewDue*
:NeorgFlashcardReviewDue
        Review only due and new cards under `flashcards_dir`, sorted oldest
        due first. See |neorg-flashcards-scheduling|.

                                                  *:NeorgFlashcardReviewFile*
:NeorgFlashcardReviewFile
        Review valid cards in the current buffer.

                                                   *:NeorgFlashcardReviewTag*
:NeorgFlashcardReviewTag [tag]
        Review cards with a matching `tags:` value.

                                                 *:NeorgFlashcardReviewScore*
:NeorgFlashcardReviewScore [bad|mid|good|new]
        Review cards by saved score.

                                                  *:NeorgFlashcardOverview*
:NeorgFlashcardOverview
        Open the full-page dashboard tab. See |neorg-flashcards-overview|.

                                                     *:NeorgFlashcardStats*
:NeorgFlashcardStats
        Open the dashboard at the analytics section.
        See |neorg-flashcards-overview|.

                                                    *:NeorgFlashcardValidate*
:NeorgFlashcardValidate
        Validate flashcard blocks in the current buffer.

                                                        *:NeorgFlashcardHelp*
:NeorgFlashcardHelp
        Open the short in-editor guide.

KEYMAPS                                         *neorg-flashcards-keymaps*

The plugin defines commands but no global keymaps. Review keys are local to
the review popup. Example global mappings:
>
  vim.keymap.set("n", "<leader>nci", "<cmd>NeorgFlashcardAdd<CR>",
    { desc = "Add flashcard" })
  vim.keymap.set("n", "<leader>ncr", "<cmd>NeorgFlashcardReview<CR>",
    { desc = "Review all flashcards" })
  vim.keymap.set("n", "<leader>ncf", "<cmd>NeorgFlashcardReviewFile<CR>",
    { desc = "Review current flashcard file" })
  vim.keymap.set("n", "<leader>nct", "<cmd>NeorgFlashcardReviewTag<CR>",
    { desc = "Review flashcards by tag" })
<

Review keys:

  Space / Enter   reveal answer, then advance
  t               type the answer and check it
  1               save score 1 and advance (requeues the card in this session)
  2               save score 2 and advance
  3               save score 3 and advance
  n               next card
  p               previous card
  e               edit source card
  q               close review

CHAPTERS AND COLLECTIONS                    *neorg-flashcards-collections*

Keep one chapter per `.norg` file under `flashcards_dir`. Open a chapter with
Neovim, add cards with `:NeorgFlashcardAdd`, and study only that chapter with
`:NeorgFlashcardReviewFile`. `:NeorgFlashcardReview` recursively combines all
chapter files under `flashcards_dir`.

Use tags for topics that span chapters. For example, add `tags: grammar` to
cards in several files and run `:NeorgFlashcardReviewTag grammar`.

`:NeorgFlashcardOpen` opens `default_file`; it is not a file picker. Keep the
default file under `flashcards_dir` when it should be part of collection
reviews.

CARD FORMAT                                   *neorg-flashcards-card-format*
>
  @flashcard japanese
  japanese: 勉強
  reading: べんきょう
  english: study
  notes: noun / suru verb
  tags: jlpt vocab
  score: 2
  reviewed: 2026-07-01
  due: 2026-07-02 08:30
  interval: 0.5
  ease: 2.5
  @end
<

`score:` and `reviewed:` are updated by the review UI when rating with 1, 2,
or 3. The same rating also maintains `due:` (local `YYYY-MM-DD HH:MM`),
`interval:` (days), and `ease:`; see |neorg-flashcards-scheduling|.

==============================================================================
SCHEDULING                                   *neorg-flashcards-scheduling*

Ratings schedule the next review with a small SM-2-style rule set:

  1 (bad)   requeues the card a few positions later in the current session and
            sets `due:` `scheduling.again_minutes` (default 10 minutes) ahead;
            ease drops by 0.2, never below `min_ease` (default 1.3).
  2 (mid)   grows the interval slowly (`* 1.2`), starting at
            `scheduling.mid_hours` (default 12 hours), so a mid card appears at
            least twice a day; ease is unchanged.
  3 (good)  multiplies the interval by the card's ease, starting at
            `scheduling.good_days` (default 3 days); ease rises by 0.05, up to
            `max_ease` (default 2.8).

New cards and cards whose `due:` has passed make up |:NeorgFlashcardReviewDue|.
Override the knobs via the `scheduling` table in setup; every key is optional:
>
  require("neorg_flashcards").setup({
    scheduling = { again_minutes = 15, good_days = 4 },
  })
<

==============================================================================
OVERVIEW AND STATS                               *neorg-flashcards-overview*

|:NeorgFlashcardOverview| opens a full-page dashboard in its own tab. The top
is a canvas that groups cards by tag, one glyph per card: red is due, yellow is
due within a day, green is scheduled, gray is new. Cards with several tags
appear in each of their groups. Below the canvas, the analytics section shows
review totals and streak, a 20-week heatmap, and a 7-day due forecast. Keys
inside the dashboard:

  h / l           move between cards
  j / k           move between rows
  Enter / r       review the due cards of the selected group in a float on top
                  of the dashboard; closing it refreshes the canvas
  a               add a card via the form (into `default_file`)
  p               peek at the selected card
  e               open the card source
  R               recollect cards
  s               jump to the analytics section
  q               close the tab

|:NeorgFlashcardStats| opens the same dashboard scrolled to the analytics.
Every rating appends one `YYYY-MM-DD HH:MM<Tab>score` line to `reviews.log`
inside `flashcards_dir`; the file is plain text and can be inspected or deleted
freely. Closing a review after one or more ratings prints a session summary.

CLOZE AND TYPED ANSWERS                            *neorg-flashcards-cloze*

Any field may contain Anki-style cloze markers:
>
  @flashcard japanese
  japanese: 東京は{{c1::日本}}の首都です
  english: Tokyo is the capital of {{c1::Japan|country}}
  @end
<
Before the reveal a marker shows as `[...]`, or `[country]` with a hint; after
the reveal it unwraps to the plain answer. Pressing `t` during review prompts
for the answer and compares it against the reveal fields with a UTF-8-aware
fuzzy match; you still rate the card yourself with 1/2/3.

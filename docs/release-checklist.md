# Study desk release checklist

Implementation started on 2026-10-15 from [the agreed design](desk-redesign.md).
This checklist records implementation, verification, and the accompanying
video preparation. Check items only after completing them.

## Plugin

- [ ] Establish baseline checks and record the release target.
- [ ] Add Desk / Overview / Stats navigation and update contextual controls.
- [ ] Render theme-aware deck boxes, category notes, and responsive layouts.
- [ ] Integrate review cards, piles, receipt, and short cancellable animations.
- [ ] Preserve retries, undo, hints, typed answers, editing, and persistence.
- [ ] Add category metadata and management, including safe tag operations.
- [ ] Add validated UI-managed decks and editable deck preferences.
- [ ] Add calendar selection, day details, forecast, and history drilldown.
- [ ] Add unique-card daily goals and honest activity/streak feedback.
- [ ] Verify narrow terminals, Unicode, dark/light themes, and reduced motion.
- [ ] Capture actual UI images, inspect them, fix issues, and capture again.
- [ ] Exercise real interaction and animation sequences.
- [ ] Run regression, clean-install, formatting, lint, and full flake checks.
- [ ] Review the final source and failure paths; resolve findings.
- [ ] Update README, help, changelog, upgrading guide, ADRs, and roadmap.
- [ ] Refresh the local Graphify index.
- [ ] Make focused commits with descriptive messages and a clean final tree.
- [ ] Record exact validation and release preparation status below.

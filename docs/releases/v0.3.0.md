# v0.3.0: Study desk and chapter management

Flashcards now opens a study desk with collection boxes, chapter notes and
card stacks. Overview manages collections, chapters and individual cards.
Stats puts progress, ratings and review trends beside a compact calendar.

- Collections keep subjects, card types, schedules and history separate.
  Chapters organize cards within a collection; tags can span chapters.
- Pending and reviewed stacks show unseen cards, retries, finished cards and
  rating totals. Daily goals count unique cards, including Again; undo reverses
  progress. Session receipts distinguish cards from answer attempts.
- Overview supports creation, rename/edit, moving cards between chapters and
  confirmed removal. Removing a chapter preserves its cards in Unfiled.
- Review adds typed-answer comparison and progressive hints, with multiline
  fields for longer answers and code. The user still chooses every rating.
- Stats includes a navigable calendar, selected-day details, review trends,
  forecasts and cards that need attention.
- Colors follow the active theme. Plain ASCII borders and reduced motion are
  available. Scratch buffers suppress visible whitespace and concealment
  locally, and shortcut help wraps in narrow windows.

## Keyboard controls

Use `hjkl` or arrows to navigate and `Ctrl-h/j/k/l` to move between panes.
Native `Ctrl-w` window commands still work. In review, `h`/Left returns,
`l`/Right reveals, and `j/k` or Up/Down browses pending cards. `H` gives a hint.
Space and Enter still reveal; a rating key cannot reveal an unseen answer.
In Stats, `Ctrl-d/u` scrolls without changing the selected date.

## Upgrading

**v0.2 configurations need updating.** The former single-root setup is replaced
by named `collections` and a `default_collection`. NVF's `schemaPresets` is now
keyed by collection ID. See the [upgrade guide](../UPGRADING.md) before updating.

Existing named-collection setups and valid scalar card files remain compatible.
Version-1 review history remains readable. Existing cards appear in Unfiled;
creating chapters is optional. Back up the collection directory, including
`.flashcards-workspace.json`, to preserve chapter organization and goals.

The plugin requires Neovim 0.10.4 or newer. Neorg is optional.
Use the v0.3.0 tag with your plugin manager or the
`github:LuixBits/luixbits-neorg-flashcards.nvim/v0.3.0` flake input.
See the [README](../../README.md) for complete installation examples and
`:help neorg-flashcards` for the manual.

## Validation

The regression suite passed locally on Neovim 0.10.4, 0.11.5 and 0.12.4.
Release checks cover clean installation without Neorg, Neorg integration,
Nix packaging, NVF module evaluation, Lua formatting and lint, documentation
and workflows. UI images were reviewed in dark and light themes, with narrow
layouts and plain ASCII borders. Windows has not been tested.

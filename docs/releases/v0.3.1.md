# v0.3.1: Consistent card entry

Notes and long answers are now editable directly in the card form. Tab moves
through every field without leaving Insert mode, and Ctrl-S saves the entire
card. The separate multiline editor and its apply step are gone.

- Labels sit above the inputs and identify front/answer fields and required
  values. The header shows the collection, chapter, card type, and destination.
- Multiline values expand in place and wrap to the window. Native o/O,
  multiline paste, and undo/redo preserve field boundaries and indentation.
- Tab and Shift-Tab select fields in both modes. In Insert mode, Enter advances
  and saves on the final field. Native j/k and arrows navigate editable lines.
- Completion and pairing plugins can no longer replace the form's navigation,
  save shortcuts, or deletion guards. This includes the Blink integration.
- Colors follow the active theme, with compact layouts and plain ASCII borders
  available. See the [reviewed composer images](../demo/README.md#card-entry-refinement).

## Upgrading

No configuration or card migration is needed from v0.3.0. Existing cards,
line breaks, indentation, IDs, scheduling data, and chapter assignments are
preserved. Neovim 0.10.4 or newer is required; Neorg remains optional.

Update your plugin manager's tag to `v0.3.1`, or use the
`github:LuixBits/luixbits-neorg-flashcards.nvim/v0.3.1` flake input. Nix users
must refresh the plugin's lock entry before rebuilding. See the
[upgrade guide](../UPGRADING.md#card-entry-update-in-v031) for the entry controls.

## Validation

The regression suite passed on Neovim 0.10.4, 0.11.5, and 0.12.4. The x86_64
Linux flake checks cover packaging, clean installation, Neorg integration,
NVF module evaluation, Lua formatting and lint, documentation, and workflows.
Real input was tested in the configured NVF editor with Blink. Screenshots
were reviewed in dark and light themes and a compact ASCII layout.

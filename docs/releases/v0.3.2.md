# v0.3.2: Clear workspace dialogs

Management menus, deletion confirmations, and small inputs now open in a
compact bordered box using the desk's colors and ASCII setting. No extra
picker configuration is needed.

- `m` shows actions for the selected collection, chapter, or card. Tag
  appearance and UI-created collection preferences have their own submenus.
- Deletion names the target, explains what gets removed or kept, and starts
  on Cancel. Existing backups, source checks, and history protection remain.
- Menus use j/k, Ctrl-j/k, or arrows, Enter to choose, h to go back, and q/Esc
  to cancel. Long lists support Ctrl-D/U and gg/G.
- Inputs support normal Neovim editing. Enter confirms; Esc returns to Normal
  mode, where q cancels. Invalid values stay visible with an explanation.
- Closing or leaving a dialog cancels it safely. Unclosed card blocks do not
  offer deletion, and configured collections do not offer detachment.

See the [reviewed dialog images](../demo/README.md#workspace-dialogs) for dark,
light, and compact ASCII layouts.

## Upgrading

No configuration or card migration is needed from v0.3.1. Card files, IDs,
chapter assignments, scheduling, and history stay compatible. Neovim 0.10.4
or newer is required; Neorg remains optional.

Update your plugin manager's tag to `v0.3.2`, or use the
`github:LuixBits/luixbits-neorg-flashcards.nvim/v0.3.2` flake input. Nix users
must refresh the plugin's lock entry before rebuilding. See the
[upgrade guide](../UPGRADING.md#workspace-dialogs-in-v032) for the menu paths.

## Validation

The regression suite passed on Neovim 0.10.4, 0.11.5, and 0.12.4. The full
x86_64 Linux flake checks cover packaging, clean installation, Neorg
integration, NVF module evaluation, formatting, lint, documentation, and
workflows. Real keyboard input was tested in the configured NVF editor with
Blink, including renaming, card creation, cancellation, resizing, and deletion.
Seven captures were reviewed across dark and light themes and ASCII borders.
